# SkillBridge AI | Career Skill Analyzer

## Project Overview
SkillBridge AI is a web-based career skill analyzer designed to help students understand their skill gaps and prepare for their desired career roles.

Users can upload their resumes or manually enter their skills. The application analyzes the available skills and generates a career readiness report.

## Features
- Resume upload and skill extraction
- Career role selection
- Skill matching and gap identification
- Career readiness percentage
- Personalized learning roadmap
- Recommended learning resources
- Interactive skill analytics charts
- Previous analysis history using SQLite

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js
- SQLite

## How to Run the Project

1. Clone the repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open your browser and visit:

   `http://127.0.0.1:5000`

## Project Goal
To help students identify their skill gaps, discover learning resources and make informed decisions about their career preparation.
